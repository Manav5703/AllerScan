 AllerScan is a mobile app for Android that uses AI to scan food labels, extract ingredients via OCR, and detect allergens based on Canadian standards. It runs offline for privacy and accessibility.

 ## Features
 - Image upload of food labels.
 - On-device allergen detection (e.g., peanuts, dairy).
 - Real-time alerts in-app.

 ## Setup
 ```bash
 npm install
 cd android && ./gradlew clean && ./gradlew assembleDebug
 ```
